# tools/

Outils pour le workflow Bitwig → Basic Frendo.

## Scripts Python

- **bitwig-to-frendo.py** : Convertisseur MIDI avancé avec options
- **quick-convert.py** : Conversion automatique rapide

## Usage

```bash
# Setup
pip install mido

# Conversion rapide
python3 tools/quick-convert.py

# Conversion avancée  
python3 tools/bitwig-to-frendo.py --help
```

Voir `docs/BITWIG-WORKFLOW.md` pour le guide complet.
