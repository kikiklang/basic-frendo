# src/

Code source C de Basic Frendo.

## Fichiers

- **main.c** : Programme principal et boucle MIDI
- **basic_frendo.h** : Déclarations communes et structures
- **json_parser.c** : Parseur de fichiers JSON  
- **midi_handler.c** : Interface ALSA MIDI
- **frendo_core.c** : Logique métier (séquençage)
- **utils.c** : Fonctions utilitaires

## Architecture

Le code est organisé en modules fonctionnels indépendants pour faciliter la maintenance et les tests.
